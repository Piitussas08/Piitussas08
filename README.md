### About me

I build games from both sides: I write the gameplay code in **Unity / C#** and I model and animate in **Blender**.

- 🎓 Finishing a Higher Technical Degree in **3D Animation & Game Environments** at Florida Universitària (Valencia)
- 🏢 Internship at **Valentia Studio**, where I worked on *Roller Hunter*
- 🎮 Currently co-developing **UN-CREDIBLES**, a local/online party game in Unity 6
- 🎯 Goal: contributing to a major game release
